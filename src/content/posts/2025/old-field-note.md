Sometimes an old post is still useful as historical context even though its instructions should no longer be followed. Set `archived: true` to display a clear notice while preserving the original URL.

Use `noindex: true` when the page should remain accessible but should not be included in search indexes, post listings, RSS, or the sitemap.
